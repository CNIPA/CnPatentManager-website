使用指南

按实际操作顺序排列：先准备环境与安装，再建库、导入数据，然后进入日常使用， 最后是期限年费、备份恢复与常见问题。

一、准备环境

中国专利管理大师是一款 Windows 桌面程序，运行在 Windows 10 / 11（x64）上。 在安装软件本身之前，机器上需要先有两项前置组件： .NET 8 Desktop Runtime（x64）与 SQL Server LocalDB 2019 或更高版本。

.NET 8 桌面运行时

从 .NET 官方下载页获取「.NET Desktop Runtime 8.x」的 x64 安装包并安装： dotnet.microsoft.com/download/dotnet/8.0。 注意选择 Desktop Runtime，而不是仅含命令行工具的 Runtime。

SQL Server LocalDB

LocalDB 随 SQL Server Express 安装包一起分发：运行 SQL Server 2019 / 2022 Express 的安装程序时， 勾选 LocalDB 组件即可。也可以用包管理器安装：

winget install Microsoft.SQLServer.2022.Express
安装向导会自动检测这两项前置组件。 缺少其中任何一项时，向导会给出「一键下载并安装」入口（需联网，安装时会有系统权限确认）； 也可以先手动装好组件，再运行安装包。

二、安装

有两种部署方式，任选其一。两者对前置组件的要求完全相同。

方式一：安装包

运行 Setup_CnPatentManager.exe，按向导完成安装。 默认安装目录是 %LOCALAPPDATA%\Programs\CnPatentManager， 位于当前用户目录下，不需要管理员权限。向导过程中会检测 .NET 8 Desktop Runtime 与 SQL Server LocalDB，缺失时给出「一键下载并安装」入口（需联网，安装时会有系统权限确认）。

安装会在开始菜单创建程序与卸载快捷方式，并注册 .cpam 文件关联 —— 之后双击数据库指针文件就能直接打开；是否创建桌面快捷方式可以在向导中勾选。

方式二：免安装（便携目录）

把维护者提供的程序目录整体复制到目标机器，双击其中的 CnPatentManager.exe 即可运行，不写注册表、不改动系统设置。 目标机器同样需要预先安装 .NET 8 Desktop Runtime 与 LocalDB。

便携方式不注册文件关联。 指针文件的关联由安装包写入；使用便携目录时， 请在数据库选择窗口中用「打开数据库文件 (.mdf)…」挂接数据库。

三、建库或挂接数据库

第一次启动会先出现数据库选择窗口，按实际情况选一种：

  1. 新建数据库：在本机数据库引擎上创建一个空库，结构由软件自动建立。
  2. 打开数据库文件 (.mdf)：挂接别人交付或从旧机器带过来的数据库文件。
  3. 打开 .cpam 指针文件：安装了软件时，直接双击 .cpam 即可。

软件在创建或打开数据库时会自动建立所需结构，并把它补齐到与程序一致的版本。

旧库不需要手工改表。把旧版本的数据库交给新版本程序打开， 软件会自动补齐缺失的内容。升级前建议先做一次备份（见第七节）。

挂接 .mdf 时，把 .mdf 与同名的 .cpam 放在同一目录最省事；只拿到 .mdf 也能用「打开数据库文件 (.mdf)…」指定。

四、导入数据

数据入口按来源分为四类，可以分批导入，互不影响。

通知书与证书 PDF

文书识别会按文书类型分流：通知书与证书写入「通知书清单」，同时更新或新建对应专利。 重复导入按发文序号幂等去重；没有发文序号时，按 申请号 + 发文日 + 通知书名称兜底判断，同一份文书不会重复入库。

公开公告文本

只更新专利本身：公开号、公开日、公告号、公告日与案件状态，不写入通知书清单。

CPC 压缩包

解析卷内的清单文件，再读取同目录下的 PDF。 正文内容以 PDF 为准，发文序号以清单文件为准。

缴费订单与收据

订单、收据与收据明细三层数据分别导入，之后用「缺少收据的缴费记录」核对缺口。 收据落库会按规则回写专利状态：申请费 → 受理审查；实审费 → 等待实审提案； 年费 → 等待颁证公告并清除逾期日期；办理登记手续 → 等年登印费。

导入后先看两张表。一是「缺少收据的缴费记录」， 二是「应缴年费」。识别失败的项目会单独列出，原因区分「无文字层（扫描件）」 「缺少文本提取组件」「解析失败」三类。

五、日常使用

界面左侧是导航树，右侧是可编辑的数据网格。

导航树

树的层级按数据组织，常用入口如下：

  • 仪表板：总专利数、应缴年费、本月到期、逾期未缴，以及年费支出趋势与未来到期分布。
  • 专利：其下含「统计」（按权利人 / 按案件状态）、各权利人、状态分类 （已失效 / 当前有效 / 被驳回 / 审查中 / 未公开）、申请年份、授权年份。
  • 通知书：其下含「费用明细」。
  • 专利权利人、发明（设计）人、身份证号。
  • 代理机构 · 代理师与代理机构管理、权利人管理。
  • 缴费年度、缴费订单、收据。
  • 应缴年费：按本月、本年度与未来 1 / 3 / 6 / 12 个月分组。
  • 缺少收据的缴费记录。
  • 左下角固定「年费价格设置」入口。

表格交互

表格的操作是熟悉的数据表习惯： 单击选中、双击编辑、右键菜单；列宽与排序可以保存，下次打开保持原样。 列排序设置与网格搜索都在工具栏中打开。

导出

专利列表工具栏提供「📤 导出 Excel」，导出为 .xlsx 文件，列中可以带上当前权利人、 当前代理机构与当前代理师。

六、期限与年费

期限由统一的规则引擎计算，规则如下：

  • 起算点分界：发文日为 2024-01-20（修改后《专利法实施细则》，国务院令第 769 号） 及以后 → 自发文日起算。
  • 发文日早于该日 → 先加 15 日推定收到，再计算期间。
  • 以月计算时取最后一月的对应日；该月没有对应日则取该月最后一日。
  • 名义届满日不是中国工作日 → 顺延至其后的第一个工作日。

通知书类型对应的期间：

通知书类型对应的期间
第一次审查意见通知书4 个月
第二次及以后审查意见通知书2 个月
驳回决定3 个月（复审请求）
复审决定书3 个月（起诉）
办理登记手续通知书 / 授予专利权通知书2 个月

以申请日起算的事项（例如缴纳申请费的期限 = 申请日 + 2 个月）走同一套规则。

「应缴年费」节点按本月、本年度与未来 1 / 3 / 6 / 12 个月分组；年费金额来自「年费价格」， 在左下角的「年费价格设置」中维护。

节假日数据按年下载并缓存。 机器离线时会退回「仅按周末」判断，因此跨春节、国庆等长假期的期限， 建议联网更新节假日数据后再复核一次。

七、备份、恢复与移交

数据库选择窗口里有两个固定操作：

  • 💾 备份…：生成一份独立的备份文件，不必停用软件。
  • ↩ 从备份恢复…：先展示备份内的内容清单， 再由你指定恢复到哪个位置。

需要把数据库交给同事时，可在数据库选择窗口选中库后「导出为文件…」： 软件会复制出数据库文件，同时生成同名的指针文件。 把这两个文件放在同一目录一起发出， 对方双击指针文件即可打开，或用「打开数据库文件 (.mdf)…」挂接。

换机器或升级软件之前先备份。 备份生成的是独立文件，可以随移动存储一起带走； 恢复时请确认目标位置没有同名的库正在使用。

八、常见问题

扫描件 PDF 能识别吗？

2020—2022 年间的部分通知书 PDF 没有文字层，本质是扫描图片，任何纯文本提取都读不出内容。 软件不会静默失败，而是明确区分「无文字层（扫描件）」「缺少文本提取组件」「解析失败」三种原因并逐一提示， 这类文书需要手工补录。

可以多人同时使用吗？

软件定位是单机使用：数据以一个本机数据库文件的形式存在，通过文件交接共享， 不提供多用户并发写入。多人协作时，建议由一个人维护主库， 需要交给他人时导出数据库文件与同名的指针文件。

数据会联网上传吗？

不会。所有业务数据保存在本机数据库文件中。 联网只用于两件事：按年下载法定节假日与调休数据（下载后缓存，可离线使用）， 以及安装向导在缺少前置组件时提供官方下载入口。

旧版本的数据库需要手工升级吗？

不需要。软件在打开旧版本数据库时会自动把结构补齐到与程序一致的版本。 升级前建议先备份一次，便于随时回退。

为什么软件算出的期限和我手算的差一天？

先看起算点：2024-01-20 及以后发文的通知书自发文日起算； 早于该日的先加 15 日推定收到再计算。再看顺延：名义届满日不是中国工作日时， 软件会顺延至其后的第一个工作日。此外，以月计算时如果目标月份没有对应日， 取该月最后一日。手工计算时漏掉顺延或按错起算点，结果就会相差一两天。

如果机器长时间离线，软件只按周末判断工作日，法定节假日与调休带来的差异需要联网更新节假日数据后再复核。

备份文件怎么恢复？

打开数据库选择窗口，点「↩ 从备份恢复…」，选择备份文件。 软件会先展示备份内的内容清单，再由你指定恢复到哪个位置。 恢复前请确认目标位置没有同名的库正在使用。
