下载

软件以两种形式交付：安装包，或免安装的便携目录。本页说明运行环境要求、 两种形式各自的安装与使用方式，以及首次使用的三步。

系统要求

运行软件需要什么

这是一款 Windows 桌面软件，数据保存在本机，不需要额外的服务器。

操作系统Windows 10 / 11（x64）
运行组件.NET 8 Desktop Runtime（x64），安装向导会检测并给出下载入口
数据库SQL Server LocalDB 2019 或更高版本，安装向导会一并检测与提示
旧库升级打开旧版本数据库时自动补齐所需内容，不需要手工改表
安装位置默认为 %LOCALAPPDATA%\Programs\CnPatentManager，当前用户目录，不需要管理员权限
磁盘占用取决于数据量 —— 除程序本体外，还有本机数据库文件与备份文件，随专利与费用记录的规模增长
网络无云服务依赖。联网仅用于按年下载法定节假日 / 调休数据，以及安装向导下载前置组件
获取方式

两种交付形式

安装包适合分发给最终用户；便携目录适合快速试用，或在多台机器之间搬移。

Setup_CnPatentManager.exe

安装包

双击后按向导安装到当前用户目录，不需要管理员权限。

  • 注册 .cnpatdb 文件关联，双击数据库文件即可打开。
  • 在开始菜单创建程序与卸载快捷方式，桌面快捷方式可选。
  • 向导检测 .NET 8 Desktop Runtime 与 SQL Server LocalDB，缺失时提供一键下载入口。
便携目录

免安装（便携目录）

把程序目录整体复制到目标机器，运行 CnPatentManager.exe 即可，不需要安装、不需要管理员权限，也不改动系统设置。

  • 程序本体就是一个目录，删除目录即完成卸载；只在当前用户注册表登记一项 .cnpatdb 文件关联。
  • 目标机器仍需预先安装 .NET 8 Desktop Runtime 与 SQL Server LocalDB。
  • 打开数据库用「打开数据库文件 (.cnpatdb)…」，或双击已有关联的 .cnpatdb。
本页不提供下载链接。 需要安装包或便携目录，请向软件的维护者索取；两者使用同一份发布版本。
便携使用

不安装也能用

如果不想在机器上安装，用便携目录即可；换机器或回退版本，替换目录就行。

  1. STEP 01

    复制

    把程序目录整体复制到目标机器（U 盘、共享目录、压缩包都可以）。

  2. STEP 02

    确认环境

    确认目标机器已装好 .NET 8 Desktop Runtime 与 SQL Server LocalDB。

  3. STEP 03

    启动

    双击目录中的 CnPatentManager.exe 启动程序。

便携方式的取舍

  • 只在当前用户注册表登记 .cnpatdb 文件关联（程序启动时自动写入，双击数据库文件即可打开）；卸载就是删除目录。
  • 删掉程序目录后，那条 .cnpatdb 关联会指向已不存在的程序，可在 Windows「默认应用」里清除。
  • 数据保存在本机数据库文件中，与程序目录无关；换机器时按使用指南的备份与移交一节处理。
备份与移交说明
安装之后

安装包会做这几件事

安装目录当前用户目录下，按用户安装，不需要管理员权限
文件关联双击 .cnpatdb 数据库文件即可直接打开对应数据库
快捷方式开始菜单创建程序与卸载入口；桌面快捷方式可在向导中勾选
权限按当前用户安装，不需要管理员权限（前置组件安装时会有系统权限确认）
前置检测检测 .NET 8 Desktop Runtime（x64）与 SQL Server LocalDB，缺失时给出下载入口

安装向导里的两个前置组件

.NET 8 Desktop Runtime 与 SQL Server LocalDB 都是必需项：缺少前者的程序无法启动， 缺少后者的数据库无法创建。向导会检测并给出「一键下载并安装」按钮（需联网）， 也可以提前手动装好再运行安装程序。

LocalDB 随 SQL Server Express 安装包分发，安装时勾选 LocalDB 组件即可； 详细步骤见使用指南 · 准备环境。

首次使用

三步看到自己的数据

  1. 01

    建库

    首次启动选择「新建数据库」，创建一个新的空数据库； 已有数据库文件时选「打开数据库文件 (.cnpatdb)」，或直接双击 .cnpatdb。

  2. 02

    导入

    导入通知书与证书 PDF、公开公告文本、CPC 卷、缴费订单与收据，数据即进入台账。

  3. 03

    核对

    在仪表板确认专利总量与逾期未缴，再打开「缺少收据的缴费记录」与「应缴年费」两张清单， 处理突出显示的行。
